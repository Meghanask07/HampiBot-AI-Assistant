# HampiBot AI Assistant 

HampiBot is an AI-powered chatbot that provides information about Hampi, Vijayanagara Empire, tourism, and culture.

## Features
- AI-powered chatbot using Gemini API
- Real-time responses
- Interactive chatbot UI
- Tourism and historical guidance

## Tech Stack
- React
- TypeScript
- Gemini API

## Future Improvements
- Firebase integration
- Chat history
